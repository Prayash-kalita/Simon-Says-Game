 Simon Says Game

This is a memory-based game developed using HTML, CSS, and JavaScript. The main objective of the game is to remember and repeat the sequence of colors displayed by the game.

Technologies Used

HTML
CSS
JavaScript

How to Play

1. Press any key to start the game.
2. Observe the sequence of colors displayed.
3. Click the color buttons in the same sequence.
4. Each correct sequence increases your level.
5. Clicking the wrong color ends the game.

Features

1. Interactive gameplay
2.Increasing difficulty levels
3. Memory and concentration challenge

How to Run

Download or clone this repository to your computer and open the index.html file in your web browser.
